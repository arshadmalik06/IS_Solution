## Brand & Style
The design system delivers an authoritative, precision-engineered interface crafted specifically for institutional compliance, standards verification, and regulatory intelligence workflows. Tailored for legal counsel, regulatory compliance officers, quality assurance auditors, and enterprise risk analysts, the UI projects unwavering computational rigor and institutional trust.

The visual style blends **Modern Technical Institutional** with **Precision Glass Layering**:
- Deep, obsidian structural canvases that eliminate ambient eye fatigue during extensive technical audits.
- Structured, data-dense hierarchy inspired by official statutory publications and high-throughput financial terminals.
- Uncompromising legibility paired with luminous semantic cues for rapid cross-referencing, statutory clause validation, and compliance tracking.
- Visual elements feel deliberate, calibrated, and immutable, evoking absolute technical verification rather than casual dialogue.

## Colors
The palette balances deep spatial absorption with luminous functional accents, engineered specifically for sustained analytical reading and statutory compliance verification.

### Surface Architecture & Canvas
- **Main Canvas (Obsidian Pitch):** `#070e18` forms the bedrock canvas, absorbing background distractions.
- **Sidebar & Navigation Base:** `#050b14` establishes an anchor pane with razor-thin containment.

## Typography
Plus Jakarta Sans serves as the primary typographic voice across all viewport tiers. Its crisp geometric proportions and sculpted counters yield high clarity in dense data tables, standard clauses, and AI generation panels.

### Typographic Principles
- **Clarity over Flourish:** Pure geometric weights eliminate ambiguity between alphanumeric standards codes (e.g., distinguishing "IS 15820" from legal citations).
- **Proportional Numerics:** Numeric data in validation panels must use tabular lining (`tnum`) to ensure aligned financial metrics, compliance clauses, and section hierarchies.
- **Monospace Integration:** Standards identifiers, legal code hashes, and JSON schema snippets drop into `JetBrains Mono` at `body-code` specs to visually detach programmatic parameters from conversational syntheses.
- **All-Caps Restraint:** `label-sm` is reserved exclusively for system micro-badges, audit classification states (e.g., `MANDATORY`, `ENFORCEABLE`), and table column supertitles.

## Layout & Spacing
The layout adheres to a fixed-fluid hybrid architecture: fixed analytical sidebars flanking a responsive, fluid workspace that caps at an expansive `88rem` standard viewport for data parity across monitor configurations.

### Grid & Structural Geometry
- **Primary Grid Model:** 12-column adaptive layout with fluid interior gutters (`1.5rem` on desktop, `1rem` on tablet/mobile).
- **Three-Pane Analytical Division:**
  1. *Global Navigation & Scope Ledger (Left):* Fixed width `17.5rem` (`sidebar-width`), dark pitch obsidian background `#050b14`.
  2. *Central Intelligence Stream (Center):* Fluid conversational and comparative synthesis viewport.
  3. *Statutory Clause Inspector (Right / Collapsible):* Fixed width `22rem` (`inspector-width`), elevated dark navy-slate `#0d1929`.

### Breakpoint Matrix
- **Desktop (>= 1280px):** Full 3-pane layout visible simultaneously. Continuous side-by-side verification enabled.
- **Tablet / Small Laptop (768px - 1279px):** Inspector transitions into a right-docked sliding drawer over central intelligence stream. Sidebar collapses to an icon rail (`4.5rem`).
- **Mobile (< 768px):** Single-column stacked stream. Global nav collapses into an app-bar sheet; statutory citations trigger full-height sheet modals.

## Elevation & Depth
Elevation is expressed through **tonal stratification and perimeter illumination** rather than heavy drop shadows, reinforcing an analytical darkroom atmosphere.

### Depth Tiers
- **Base Ground (Level 0):** `#070e18` (Canvas). Flat, absorbs light, anchors the workspace.
- **Structural Framing (Level 1):** `#0d1929` bordered with 1px solid `#1f3350`. Used for standard cards, search inputs, and list panels.
- **Interactive Focus (Level 2):** `#132238` bordered with 1px solid `#223859`, accompanied by a subtle ambient perimeter glow: `0 4px 20px -2px rgba(5, 11, 20, 0.75), 0 0 0 1px rgba(31, 51, 80, 0.4)`.
- **Floating Overlays & Menus (Level 3):** `#182840` with 1px solid `#2b7fff40` and pronounced ambient dispersion: `0 12px 32px -4px rgba(0, 0, 0, 0.8), 0 0 16px 0 rgba(29, 111, 229, 0.1)`.
- **Dialogue Message Stacking:**
  - *User Query Bubble:* `#152744` with a crisp 1px `#1f3350` top and right edge highlight.
  - *System Response Block:* Blends directly into `#0d1929` with a solid royal blue left anchor border (3px width, `#1d6fe5`).

## Shapes
The design system employs precise, disciplined curvature calibrated to balance institutional firmness with modern software aesthetics.

### Radius Assignments
- **Micro UI (`rounded-sm` / 4px):** Checkbox indicators, table status pill pips, and code tags.
- **Standard Controls (`rounded-md` / 8px):** Primary buttons, input fields, dropdown triggers, and interactive chips.
- **Card Containers (`rounded-lg` / 16px):** Clause viewports, audit summary cards, analytical graphs, and user query bubbles.
- **Floating Surfaces (`rounded-xl` / 24px):** Search command bar (Spotlight / Omnibar), conversational floating action hubs, and modal dialogue overlays.
- **Status Pills (`rounded-full`):** Strictly reserved for regulatory classification badges and verification tags.
